# Hexel Terminal Agent — Releases

Prebuilt terminal binaries for **macOS** (Apple Silicon & Intel), **Windows x64**, and **Linux x64**.

## Quick Install

### macOS / Linux (Terminal)

```bash
curl -fsSL https://raw.githubusercontent.com/Zokker1/hexel-releases/main/install.sh | bash
```

### Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/Zokker1/hexel-releases/main/install.ps1 | iex
```

After installation, start Hexel inside any project folder:

```bash
hexel
```
